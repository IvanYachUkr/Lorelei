# LoRA Training Contract

## Objective

Train a Stable Diffusion 1.5 style adapter for
`a busy market, in <sks> style`. The final file contains UNet LoRA weights,
text-encoder LoRA weights, and the learned `<sks>` embedding.

## Inputs

- Stable Diffusion 1.5.
- Images from `--data_dir`.
- Optional captions from `--captions_jsonl`.
- Optional permitted auxiliary images and sampling weights from
  `--auxiliary_jsonl`.
- One new tokenizer token from `--instance_token`.

The selected run uses 843 supplied images, fixed Florence-2 captions, and 60
images generated by unmodified Stable Diffusion 1.5. It uses no image from the
assignment PDF, external dataset, or adapter-generated source.

## Output

`--output_dir/pytorch_lora_weights.safetensors` is the only output file. It
contains both LoRA branches and `__custom_token_embedding__`.

## Algorithm

1. Load the supplied images and optional captions and auxiliary rows.
2. Build a deterministic weighted draw schedule from the training seed.
3. Load the Stable Diffusion 1.5 tokenizer, text encoder, VAE, UNet, and DDPM
   scheduler.
4. Add `<sks>` as one token and initialize its embedding from the mean embedding
   of `ghibli style`.
5. Freeze the base models. Attach LoRA to UNet `to_q`, `to_k`, `to_v`, and
   `to_out.0`, and to text-encoder `q_proj`, `k_proj`, `v_proj`, and `out_proj`.
6. Resize, crop, and optionally flip each image from a deterministic per-draw
   seed.
7. Use `{caption}, in <sks> style`. Caption dropout uses
   `an animated movie scene, in <sks> style`; permitted auxiliary market rows
   may use the assignment prompt according to their recorded probability.
8. Encode the image with the frozen VAE and add deterministic noise at a
   deterministic timestep.
9. Compute Min-SNR-weighted diffusion MSE.
10. Disable both adapters and predict the same noisy latent from the plain
    content prompt. Penalize the adapted prediction's deviation from this
    frozen-base prediction.
11. Penalize movement of the learned token from its initialization.
12. Accumulate gradients, clip them, and update UNet LoRA, text-encoder LoRA,
    and the standalone token row with AdamW and cosine decay.
13. Save both LoRA state dictionaries and the token row in one Safetensors
    file.

## Selected Configuration

- 512x512, seed 2202, fp16, random crop and horizontal flip.
- UNet rank 16, text-encoder rank 4, LoRA dropout 0.05.
- Learning rates: `7e-5`, `2.5e-6`, and `1e-5`.
- Min-SNR gamma 5, preservation weight 0.65, token-anchor weight 0.05.
- Batch size 1, gradient accumulation 4, caption dropout 0.08.
- Cosine schedule registered for 500 steps with 50 warmup steps.
- Train 250 optimizer steps, the visually selected point on that schedule.

## Assumptions

- Full training uses a CUDA GPU with about 8 GB of VRAM.
- Without a captions file, the trainer uses the generic style prompt for every
  supplied image.
- Different GPU architectures may reproduce the method without producing
  byte-identical floating-point weights.

## Edge Cases

- Existing output requires `--overwrite`.
- Caption files must cover every supplied image exactly once.
- Every styled prompt contains the instance token once; plain preservation
  prompts contain no instance token.
- Only LoRA parameters and the standalone token row receive gradients.
- `--max_steps` cannot exceed `--scheduler_steps`.

## Expected States

1. The tokenizer grows by one token.
2. The selected schedule contains 2,000 draws; training consumes the first
   1,000 draws.
3. Each optimizer step consumes four microbatches.
4. The final file contains 256 UNet tensors, 96 text-encoder tensors, and one
   token-embedding tensor.

## Verification

1. Compile both submitted scripts.
2. Run a short CUDA smoke test.
3. Confirm the output directory contains one Safetensors file.
4. Confirm the file contains both LoRA branches and the custom token embedding.
5. Render at least three images with the assignment prompt.
